# Notebooks de referencia del profesor

Qué notebook se usa en cada parte de la fase 2:

- `03_Regresion_Logistica.ipynb`: naive y regresión logística (2.2).
- `Regresion_Ridge_Lasso.ipynb`: LASSO y Ridge (2.3).
- `Arboles_regresion. 1.ipynb`: árbol de decisión (2.3).
- `RandomForest.ipynb`: Random Forest (2.3).
- `SVM 1.ipynb`: SVM (2.3).
- `05_Hyperparameter_tunning.ipynb`: búsqueda de hiperparámetros con `GridSearchCV` (2.3).
- `06_Bagging.ipynb`: bagging (2.3) y ensamblaje (2.4).
- `07_Boosting_Xgboost_v3.ipynb`: AdaBoost, Gradient Boosting y XGBoost (2.3).
- `08_Introduccion_Deep_Learning.ipynb`: red neuronal (2.3; se hace con `MLPClassifier` porque TensorFlow no tiene versión estable para Python 3.14, D35).
- `04_Desbalanceo_de_clases.ipynb` y `t-SNEUMAP.ipynb`: otros temas del curso. Hoy no se usan; con las filas espejo las clases quedan 50/50.
